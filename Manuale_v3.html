Head/Body

head Parte del codice HTML contente il titolo della pagina e informazioni per lo più nascoste all'utente.
Esempio: <head> <title> Manuale di HTML</title> </head>
body Parte del codice HTML contente il contenuto della pagina che è visibile all'utente.
Esempio: <body> abc ABC </body>

Tag tipografici

b Bold. Rende il testo dentro al blocco in grassetto.
Esempio: <b>Bold</b>
i Italics Rende il testo dentro al blocco in corsivo.
Esempio: <i>Italics</i>
u Underline Rende il testo dentro al blocco sottolineato.
Esempio: <u>Underline</u>
s Strikethrough Rende il testo dentro al blocco barrato.
Esempio: <s>Strikethrough</s>
sup Superscript Rende il testo dentro al blocco come testo apice.
Esempio: <sup>Superscript</sup>
sub Subscript Rende il testo dentro al blocco come testo pedice.
Esempio: <sub>Subscript</sub>
code Codice_001: Rende il testo dentro al blocco in un formato grafico, simile a quello di un codice di programmazione.
Esempio: <code>Codice_001:</code>
small Rende un testo un po' più piccolo del normale.
Esempio: Rende un testo <small>un po' più piccolo</small> del normale.
h_

Dove al posto di _ c'è un numero

Rende il testo dentro al blocco come un intestazione (bold + a capo + dimensioni diverse + spaziatura sotto).
Minore il numero, maggiori le dimensioni (comprese tra 1(max) e 6 (min)).
Esempio: <h4>Dove al posto di _ c'è un numero</h4>

Liste

ol
  1. Lista ordinata.
Esempio: <ol> <!-- #TODO: items --> </ol>
ul
  • Lista non ordinata.
Esempio: <ul> <!-- #TODO: items --> </ul>
li
  1. Un
  2. elemento
  • di una lista.

  1. Primo
  2. Secondo
  3. Terzo

  2. bbbb
  3. cccc
  • Quadrato
  • Cerchio
  • Quello che vuoi

definition list
Lista di definizioni.

definition term
Termine della definizione.

Tabelle

table Struttura generale e bordo esterno di una tabella.
Esempio: <table cellspacing="0"> <!-- #TODO: righe --> </table>
tr table row. Riga di una tabella.
Esempio: <table cellspacing="0"><tr> <!-- #TODO: colonne --> </tr></table>
td table data. Cella dentro una riga di una tabella.
Esempio: <table cellspacing="0"><tr><td> Data </td></tr></table>
th
table header
Cella di intestazione dentro una riga di una tabella.
Esempio: <table cellspacing="0"><tr><th>table header</th></tr></table>

Tag vari

br Codice atomico (non si apre, non si chiude)
per andare a capo
Esempio: Hello<br>World
a Blocco contenente un link.
Esempio: <a href=""> Blocco contenente un link. </a>
center
Codice per centrare un testo (senza usare CSS).
Esempio: <center> Codice per centrare un testo (senza usare CSS). </center>
hr Horizontal Rule
serve a tirare una linea orrizzontale per dividere porzioni di pagina.
Esempio: Horizontal Rule<hr>serve a tirare una linea orrizzontale per dividere porzioni di pagina.
img Image, serve per caricare immagini in una pagina web.
Esempio: <img src="https://myimgs.org/storage/images/52667/rombo_t.png">
p Sta per

Paragraph.

Scrive un paragrafo di testo. Non può contenere altri p o div. Include un "br" doppio prima e dopo
Esempio: Sta per <p>Paragraph.</p>
div Sta per
Division
Scrive una porzione di codice. Può contenere altri div (e p).
Include un "br" singolo prima e dopo
Esempio: Sta per<div><div>Division</div> Scrive una porzione di codice. Può contenere altri div (e p).</div>
